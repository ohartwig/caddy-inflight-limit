# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, using GitHub's
[private vulnerability reporting](https://github.com/ohartwig/caddy-inflight-limit/security/advisories/new)
(the "Security" tab, then "Report a vulnerability"). Do not open a public
issue for a suspected vulnerability.

You can expect an acknowledgement within 72 hours. We will keep you informed
of progress, agree a disclosure date with you, and credit you in the advisory
if you wish.

## Supported versions

Only the latest release receives security fixes.

## Scope

This policy covers the code in this repository. Vulnerabilities in Caddy or
in other dependencies should be reported to their respective projects; we
update our dependencies when fixes are released.
